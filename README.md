# BI-дашборд «Такт»

Ветка содержит README и dashboard/: HTML/CSS/JavaScript, локальный Leaflet,
карту, интерфейс диспетчера, администрирование и руководство HTTP API.
Исходники синхронизированы с prototype; backend, ML и данные сюда не входят.

## Рабочее место диспетчера

Карта и таблица отображают парк выбранного профиля, очередь внимания,
текущую позицию, прогноз T+10…15 минут, интервал, риск, контрольную остановку
и источник данных. Карточка показывает соседние остановки и расчётные времена.
Текущее отклонение и будущий прогноз разделены. Отсутствующий прогноз
не заменяется нулём; потеря связи и архивный fallback явно обозначены.
Маршрутные линии соединяют плановые остановки, не представляют дорожный граф.

Выбор ТС в поле резерва открывает соответствующую карточку; открытие карточки
синхронизирует выбор резерва. What-if показывает компенсацию по остановкам,
не изменяя исходный прогноз. Внизу custom-карточки доступны debug-скорость
и её сброс. Есть светлая/тёмная тема, следование за ТС, фильтры и управление
двумя потоками. Окно источников закрывается кнопкой или кликом по фону.

## Центр действий

Pending и недоставка серые, исполнение синее, закрытие зелёное. Backend
закрывает ранее рискованный тикет после приёма и свежего live-прогноза
в зелёной зоне; закрытие видно 15 секунд, затем тикет удаляется.
F5 сохраняет общую для профиля сессию, перезапуск backend очищает тикеты.
Демо-реакция повышает скорость только выбранного custom-ТС без подмены ML;
для оригинального источника только подтверждает приём.

Опрос выполняется одним последовательным циклом: следующий запрос через
1 секунду после завершения предыдущего. Медленный ответ не создаёт второй
цикл. Блок действий не пересоздаётся без необходимости при каждом опросе.

## Запуск и ограничения

В полной системе адрес dashboard — http://127.0.0.1:8080/;
руководство API — /docs, Sphinx — /code/. Интерфейс обслуживается backend
через nginx; открытие HTML как локального файла не заменяет запуск системы.
Подложка карты требует внешних тайлов; линии и маркеры строятся локально.
Профили демонстрационные, без production-аутентификации. Интерфейс не
гарантирует внешнюю доставку команд или выпуск реального резерва.
