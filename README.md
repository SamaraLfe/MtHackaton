# Backend «Такт»

Эта ветка содержит только backend диспетчерской системы: FastAPI, приём NDTP,
сопоставление координат с плановой траекторией, вызов ML V5 и операционные API.
ML-сервис, дашборд, датасеты и эмуляторы поставляются отдельными ветками.

## Ответственность backend

Backend:

- принимает NDTP-пакеты по TCP и JSON-телеметрию через `POST /api/telemetry`;
- хранит историю движения в памяти и локальные профили/команды в SQLite;
- переносит расписание на календарный день live-события;
- проецирует координату на плановый сегмент и считает `current_deviation_s`;
- выбирает контрольную остановку в окне T+10…T+15;
- отправляет исходные данные в ML API `/predict_v5`;
- возвращает прогноз, риск и интервал неопределённости;
- обслуживает карту, what-if резерва, назначения диспетчеров и управление потоками.

Текущее отклонение и будущий прогноз — разные моменты одной поездки:
`current_deviation_s` относится к положению сейчас, а `prediction_s` — к целевой
остановке через 10–15 минут. Медленная телеметрия у остановки использует тот же
live-сдвиг расписания, поэтому старый календарный день не превращается в тысячи
секунд. Физически нереалистичное восстановление ограничивается и отмечается
`prediction_adjusted=true`.

Для оригинального NDTP backend при старте/первом запросе статуса восстанавливает
конфигурацию из 13 расписанных units. `waiting_for_live` означает, что unit уже
настроен, но ещё не прислал первый пакет. Если внешний образ генерирует случайные
координаты, backend сохраняет `raw_lon`/`raw_lat`, а рабочую точку проецирует на
плановую траекторию (`position_adjusted=true`).

## Запуск

Из корня полного проекта, где доступны `dataset/` и `artifacts/`:

```sh
ML_URL=http://127.0.0.1:8001 \
DATA_DIR=dataset ARTIFACT_DIR=artifacts START_MODE=live \
python -m uvicorn backend.app:app --host 0.0.0.0 --port 8000
```

Основные переменные:

| Переменная | Назначение | Значение по умолчанию |
|---|---|---|
| `ML_URL` | адрес ML API | `http://127.0.0.1:8001` |
| `DATA_DIR` | расписания и телеметрия | `dataset` |
| `ARTIFACT_DIR` | артефакты V5/метрики | `artifacts` |
| `START_MODE` | стартовый режим | `live` |
| `NDTP_PORT` | входящий TCP NDTP | `9201` |
| `CUSTOM_EMULATOR_URL` | собственный эмулятор | `http://127.0.0.1:18081` |
| `OFFICIAL_EMULATOR_URL` | оригинальный NDTP-образ | `http://127.0.0.1:18080` |

Standalone checkout этой ветки не содержит сами датасеты, ML-модель и файлы
дашборда, поэтому для рабочего запуска нужно собрать полный прототип из
соответствующих веток.

## HTTP API

Документация и интерактивное описание доступны после запуска:

- `GET /docs/swagger` — Swagger UI с примерами и группировкой операций;
- `GET /redoc` — ReDoc;
- `GET /openapi.json` — живой OpenAPI-контракт;
- `GET /health` — доступность backend;
- `GET /health/ready` — готовность расписания, артефактов и ML;
- `GET /api/state` — текущая картина, источники и прогнозы;
- `POST /api/telemetry` — пакет из 1…1000 JSON-событий;
- `POST /api/predict` — ручной прогноз по одной точке;
- `POST /api/mode`, `POST /api/replay/step` — live/replay;
- `GET /api/network`, `POST /api/map-match` — плановая геометрия;
- `GET /api/incidents`, `GET /api/risk`, `POST /api/what-if` — риски и резерв;
- `GET /api/dispatchers` и `/api/admin/dispatchers/*` — профили и назначения;
- `GET /api/admin/emulators`, `POST /api/admin/emulators/{id}/{action}` — пауза,
  остановка и возобновление потоков;
- `GET /api/driver-commands`, `POST /api/driver-commands` — локальная очередь
  указаний водителю.

`POST /api/telemetry` принимает события с `tr_id`, `event_time`, `lon`, `lat`,
`speed` и `location_valid`. Прогноз для одного ТС запускается не чаще одного раза
в 30 секунд времени событий; живая позиция обновляется на каждом валидном пакете.

## Структура кода

- `backend/app.py` — состояние, FastAPI-маршруты, прогноз и управление потоками;
- `backend/ndtp.py` — фрейминг, CRC и разбор навигационных NDTP-пакетов;
- `backend/api_docs.py` — описания операций, ошибки и OpenAPI-примеры.

При изменении API снимок контракта экспортируется из полного проекта:

```sh
python scripts/export_openapi.py
```

Дашборд и документация кода не входят в эту ветку; их описание находится в
README ветки `dashboard`.
