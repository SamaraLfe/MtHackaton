# MtHackaton

Репозиторий решения задачи прогнозирования задержек городского транспорта.

Компоненты разнесены по веткам:

- `dashboard` — интерфейс диспетчера;
- `backend` — API и приём телеметрии NDTP;
- `ml` — обучение, инференс и модельные артефакты;
- `data` — CSV-датасет;
- `integration` — общая конфигурация, тесты, документация и скрипты;
- `prototype` — собранный проект со всеми компонентами.

Архив NDTP-эмулятора опубликован в GitHub Release `dataset-v1`.
