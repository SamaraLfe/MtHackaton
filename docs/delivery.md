# Итоговый комплект

[README](../README.md) содержит инструкцию запуска и ссылки на документацию.
Интеграционная ветка prototype включает три модуля и Docker Compose.
Система разворачивается локально; адреса localhost относятся к машине запуска.

Архив формируется из зафиксированного состояния полного проекта:

```sh
python -m sphinx -W --keep-going -b html docs/sphinx docs/_build/html
python scripts/package_submission.py
```

Результат: dist/takt-submission-COMMIT.zip и .zip.sha256. В архив входят все
отслеживаемые исходники, тесты, Dockerfile/Compose, обученная модель, датасет,
artifacts/submission.csv, метрики, README, инструкция жюри, OpenAPI, Sphinx
(исходники и готовый docs/_build/html/index.html). SUBMISSION-MANIFEST.json
содержит полный commit и SHA256 каждого файла.

Не включаются .git, state/ и резервные копии БД, окружения и кэши.
Официальный образ организаторов не включён: перед запуском через
`python scripts/run_prototype.py` загрузите его по инструкции в README. Docker-образы зависимостей не включены:
для первого build нужен интернет. Датасет включён для передачи жюри как часть
отслеживаемого проекта; внешнее распространение — по условиям организаторов.

После распаковки перейдите в takt/ и следуйте README. Git для запуска не нужен.
Архив не хранится в Git и привязан к commit, указанному в манифесте.
Файл .zip.sha256 содержит контрольную сумму поставки.
