## Контроль перед отправкой

- `git status` не содержит незакоммиченных обязательных файлов;
- изменения отправлены в `origin/prototype`;
- `python scripts/run_prototype.py` заканчивается `Prototype is ready`;
- все URL из инструкции возвращают HTTP 200;
- `python -m pytest -q` завершается успешно;
- `python scripts/verify_running.py --target docker` завершается успешно;
- `artifacts/verification.json` содержит `execution_target: docker`.
