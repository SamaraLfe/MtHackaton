Такт: документация кода
========================

Эта часть документации предназначена для разработчиков проекта. Она строится
Sphinx из docstrings исходного кода и дополняет ``docs/ANALYSIS.md`` и
руководство HTTP API в ``/docs`` работающего backend.

Сначала прочитайте :doc:`overview`: там объяснены границы модулей, владение
состоянием и путь данных. Страницы модулей содержат API функций и классов,
сигнатуры, исходный код и ссылки между компонентами.
