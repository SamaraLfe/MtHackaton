# Карта диспетчерского экрана

Основная поверхность dashboard — интерактивная карта движения с контрастной подложкой Esri World Street Map и локальным Leaflet 1.9.4.

- Подложка: Esri World Street Map, подключается без API key; атрибуция отображается на карте.
- Маркеры транспорта с уровнем риска, выделение выбранного ТС и открытие инспектора.
- Плановые последовательности остановок отображаются отдельным слоем; переключатель позволяет скрыть/показать все линии.
- Кнопка общего охвата возвращает карту к сети маршрутов.
- По клику на маркер, строку таблицы или элемент Fleet Watch открывается единый drawer: источник, последняя телеметрия, прогноз, целевая остановка, интервал и рекомендация.
- При недоступных тайлах остаются локальные линии, маркеры и операционная таблица; dashboard не становится пустым.

Линии соединяют плановые остановки. Это не полноценный дорожный граф: исходная геометрия дорог и номера официальных маршрутов отсутствуют в датасете. Map matching backend также является nearest-stop matching и явно помечен в интерфейсе.

Поставщик и атрибуция тайлов настраиваются в `map-config.js`; секретные ключи в репозитории не хранятся. Интернет нужен только для картографической подложки.
